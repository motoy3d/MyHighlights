# つばさ用グループウェア Tsubasa⬆UP

サイボウズLiveに代わるグループウェアとして作成。
Webアプリケーション。PWA対応していく。基本的にスマホ向け。PCでも使用は可能。

## 機能
- 連絡事項投稿
  - 投稿一覧表示、詳細表示
  - 投稿登録、編集、削除
  - コメント投稿、編集、削除
  - いいね機能
  - ファイル添付
  - アンケート作成、回答
- スケジュール
  - 予定登録
  - カレンダー表示
- ブログ表示（RSS）
- メンバー管理
  - メンバー登録、編集、削除
  - メンバー一覧表示、詳細表示
- 設定
  - プロフィール表示、変更
  - メール通知設定
  - カレンダー同期
  - 開発者への連絡
- 認証
  - ログイン・ログアウト
  - パスワードリセット
